#Portfolio Simple Website Using HTML and CSS
📌 Project Overview

This project is a simple website developed using HTML and CSS. It consists of a Home Page and a Contact Page, designed with a clean layout and user-friendly navigation. The main goal of this project is to practice the fundamentals of web development and understand how to structure and style web pages.

✨ Features
Home Page: Introduces the website with a simple and attractive layout.
Contact Page: Provides contact information for visitors to connect.
Navigation Menu: Allows users to navigate between the homepage and contact page.
CSS Styling: Uses colors, fonts, spacing, and layouts to improve the website's appearance.
Simple Design: Focuses on readability and ease of use.
Responsive Layout: Includes styling to help the pages adapt to different screen sizes, if configured.
🛠️ Technologies Used
HTML5 – Used to create the structure and content of the web pages.
CSS3 – Used to style the pages, manage layouts, and improve the visual appearance.

🚀 How to Run the Project
Clone or download this repository.
Open the project folder in Visual Studio Code or another code editor.
Make sure all HTML and CSS files are in the correct locations.
Open index.html in your web browser.
Use the navigation menu to visit the contact page.
